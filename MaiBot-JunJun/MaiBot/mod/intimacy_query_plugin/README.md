# 好感度查询插件

这个插件提供好感度查询功能，用户可以通过关键词查询自己的好感度信息。

## 功能特点

- ✅ 通过关键词触发好感度查询
- ✅ 使用大模型生成自然、口语化的回复
- ✅ 根据好感度等级调整语气和亲密程度
- ✅ 不使用生硬的模板，每次回复都不同

## 功能

- 通过关键词触发好感度查询
- 使用大模型根据好感度信息生成自然的回复
- 根据关系等级（陌生/熟人/好友/挚友/恋人）调整语气
- 包含好感度数值、心情值、聊天次数等信息

## 触发关键词

用户发送以下任意关键词即可查询好感度：

- 好感度
- 亲密度
- 关系值
- 我们的关系
- 查询好感度
- 查询亲密度
- 查看好感度
- 查看亲密度
- 好感
- 亲密
- 关系
- 喜欢我吗
- 对我的印象

## 回复特点

### 1. 自然口语化

不使用生硬的模板，而是用机器人自己的话语表达：

**生硬模板（旧版）：**
```
📊 关系信息查询
👤 用户：张三
💖 好感度：65.0/100
```

**自然表达（新版）：**
```
嗯...���我想想，我对你的好感度大概有 65 分左右呢~
我们现在算是好朋友啦，聊了好多次天了，
感觉和你聊天挺开心的喵~
```

### 2. 根据关系等级调整语气

- **挚友/恋人（80-100分）：** 更亲密、随意、可以撒娇
  ```
  哎呀，你还问这个呀~ 我对你的好感度都快满了呢，有 92 分！
  我们可是最好的朋友了，和你聊天总是特别开心~
  ```

- **好友（60-79分）：** 轻松友好、可以开玩笑
  ```
  嗯...我对你的好感度是 68 分哦~
  我们现在关系还不错呢，算是好朋友啦！
  ```

- **熟人（40-59分）：** 友好但保持一定距离
  ```
  我对你的好感度是 52 分，我们算是比较熟悉的朋友了。
  多聊聊天的话，关系会更好的~
  ```

- **陌生（0-39分）：** 礼貌友好、鼓励多交流
  ```
  我对你的好感度是 28 分，我们还不太熟呢。
  不过没关系，多聊聊天就能增进了解啦~
  ```

### 3. 包含关键信息

虽然是自然表达，但会包含：
- 好感度数值
- 关系等级描述
- 心情状态
- 聊天次数
- 恋人关系（如果有）

### 4. 每次回复不同

由于使用大模型生成，每次查询的回复都会有所不同，更加自然真实。

## 技术实现

- 使用 `LLMRequest` 调用大模型生成回复
- 根据好感度数据构建详细的提示词
- 提示词中包含关系等级、好感度、心情值等信息
- 要求大模型用自然、口语化的方式表达
- 根据不同关系等级调整语气和亲密程度

## 配置要求

需要启用关系系统：

```toml
[relationship]
enable_relationship = true
```

## 注意事项

1. 需要用户先与机器人聊天，才会有好感度记录
2. 每次查询会消耗一定的 token（用于生成自然回复）
3. 回复内容由大模型生成，每次可能略有不同
4. 如果大模型生成失败，会返回友好的错误提示
