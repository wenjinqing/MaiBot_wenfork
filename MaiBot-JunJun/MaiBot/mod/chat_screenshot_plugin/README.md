# 聊天记录截图插件

## 功能介绍

这个插件可以截取特定用户的聊天记录并生成类似微信/QQ风格的聊天截图，主要用于举证场景。

## 主要特性

1. **智能截图生成**：自动生成美观的聊天记录截图
2. **灵活筛选**：支持按用户、聊天类型（群聊/私聊）筛选
3. **举证功能**：当用户否认说过某些话时，可以截图举证
4. **大模型调用**：作为Action供大模型自动判断何时使用
5. **手动触发**：支持命令手动触发

## 使用场景

### 1. 举证场景
用户在群里说："我没说过这话"
→ 大模型自动调用截图功能，截取该用户的历史消息并发送到群里

### 2. 查看历史
用户说："我之前说了什么？"
→ 大模型截取该用户的历史消息并发送截图

### 3. 跨会话查看
用户在私聊问："我在群里说了什么？"
→ 大模型截取群聊记录并发送到私聊

## 使用方法

### 大模型自动调用（推荐）

大模型会在以下情况自动调用：
- 用户否认说过某些话
- 用户要求查看历史聊天记录
- 需要举证的场景

**Action参数：**
```python
{
    "user_id": "用户ID",           # 必填
    "platform": "平台（如qq）",     # 必填
    "message_count": 20,           # 可选，默认20条
    "chat_type": "all",            # 可选：group/private/all
    "send_to": "current"           # 可选：current/private/group
}
```

### 手动命令触发

```bash
/screenshot          # 截取最近20条消息
/screenshot 30       # 截取最近30条消息
```

## 配置说明

### 基本配置 (config.toml)

```toml
[general]
default_message_count = 20    # 默认截取消息数量
max_message_count = 100       # 最大截取消息数量
screenshot_width = 800        # 截图宽度
font_size = 16                # 字体大小
show_timestamp = true         # 是否显示时间戳

[style]
background_color = "#F5F5F5"      # 背景颜色
user_bubble_color = "#95EC69"     # 用户消息气泡（绿色）
bot_bubble_color = "#FFFFFF"      # 机器人消息气泡（白色）
text_color = "#000000"            # 文字颜色
timestamp_color = "#999999"       # 时间戳颜色
bubble_radius = 8                 # 气泡圆角半径
message_spacing = 10              # 消息间距
```

## 截图样式

生成的截图包含：
- ✅ 消息时间戳（可配置显示/隐藏）
- ✅ 用户昵称
- ✅ 消息内容（自动换行）
- ✅ 类似微信的气泡样式
- ✅ 用户消息（绿色气泡，右对齐）
- ✅ 机器人消息（白色气泡，左对齐）

## 依赖

- Pillow：用于图片生成

安装依赖：
```bash
pip install Pillow
```

## 注意事项

1. **隐私保护**：截图会包含真实的聊天内容，请谨慎使用
2. **消息数量限制**：最多截取100条消息，避免生成过大的图片
3. **字体支持**：Windows系统使用微软雅黑字体，其他系统使用默认字体
4. **存储空间**：截图会保存在项目根目录，建议定期清理
