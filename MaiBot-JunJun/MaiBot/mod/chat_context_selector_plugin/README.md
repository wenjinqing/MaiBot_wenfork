# 聊天上下文选择插件

## 功能介绍

这个插件让大模型可以智能选择查看私聊或群聊的历史记忆，实现上下文的灵活切换。

## 使用场景

### 1. 用户在群聊中提到私聊内容
```
用户（在群里）："我私下跟你说过这件事"
→ 大模型调用 context_type='private'，查看私聊记录
```

### 2. 用户在私聊中询问群聊内容
```
用户（私聊）："我在群里说了什么？"
→ 大模型调用 context_type='group'，查看群聊记录
```

### 3. 用户明确区分场景
```
用户："你还记得我们单独聊过的那件事吗？"
→ 大模型调用 context_type='private'
```

## Action参数

```python
{
    "context_type": "private",  # private/group/all
    "reason": "用户提到私聊内容"  # 可选，说明原因
}
```

## 工作原理

1. 大模型检测到用户提到特定场景（私聊/群聊）
2. 调用此Action设置上下文偏好
3. 后续的记忆检索会根据这个偏好筛选记录
4. 确保回复基于正确的上下文

## 配合使用

此插件需要配合：
- **聊天记录截图插件**：可以截取特定类型的聊天记录
- **记忆检索系统**：根据上下文类型筛选记忆
- **query_chat_history_by_type工具**：按聊天类型查询记录
